# Synthetic evaluation demonstration

These outputs use 22 artificial lesion IDs and constructed probabilities. They
verify the evaluator and illustrate its output format; they are **not trained-model
results**. There are two examples per class and four deliberate errors.

- [Overall metrics](metrics.json)
- [Per-class metrics](per_class_metrics.csv)
- [Count confusion matrix](confusion_matrix.png)
- [Normalized confusion matrix](confusion_matrix_normalized.png)

Inputs are in [examples/evaluation](../../examples/evaluation). Reproduce this
demonstration using the command in the [evaluation guide](../../docs/evaluation.md).
