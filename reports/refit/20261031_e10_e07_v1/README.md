# E10 主模型与 E07 对照的最终 refit

两组于 2026-10-31 完成训练并通过四个最终 checkpoint 的 CPU 内容核对和严格加载。
随后在同一固定 1,037 例 holdout 上完成评估，结果见 [最终报告](../../holdout/20261031_holdout_e10_e07_v1/SUMMARY.md)。

| 模型 | 角色 | 五折最佳 epoch | 固定 refit 轮数 | 训练记录 | 验证记录 | 作业耗时 |
|---|---|---|---:|---:|---:|---|
| E10 | 主模型 | 9、51、21、10、13 | 13 | 24,247 | 0 | 16 分 29 秒 |
| E07 | 对照 | 48、14、40、9、14 | 14 | 24,247 | 0 | 17 分 35 秒 |

轮数取各自五折最佳 epoch 的中位数。两组从 ImageNet V2 独立初始化模型和优化器，
不从 CV checkpoint 续训；使用全部 3,968 个 MILK 开发病例＋20,279 张 ISIC 训练图。
类别权重按完整训练侧重算，E10 另在完整训练侧重新拟合 28 维元数据编码，E07 不使用元数据。
不做验证早停，也不使用 holdout 选轮数。主模型／对照角色在最终评估前固定。

每组 H100 MIG 1g.10gb、4 CPU、24G 主机内存，batch 32、4 workers、BF16、
channels_last、TF32；cuDNN benchmark=False、deterministic=True。时间包含数据暂存与保存开销。

## 已完成的 checkpoint 核对

四个 best／last 文件均可安全读取并严格加载，`refit_complete=true`、epoch 为 13／14。
每组 best／last 的最终模型参数一致；冻结参数与 ImageNet 一致，layer4 已更新，模型和
优化器状态有限。完整训练侧类别权重、E10 元数据、逐轮记录与采样／优化步数均已核对。
这项 CPU 核对与后续实际 holdout 推理分别记录，不是再次训练。
