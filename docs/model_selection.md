# 模型选择与固定 holdout 边界

以下逐折选 epoch、早停和 refit 轮数规则在正式训练前确定。2026-10-31，小组决定把“最好的配置”用于 refit；按项目既有主指标“五折平均九类 Macro F1”核对，E10 在十一组中唯一最高（57.00%），pooled OOF Macro F1 也最高（56.92%）。用户随后明确授权 **E10 为主模型、E07 为对照**，两组 refit 训练已完成，分别为 13／14 轮，四个最终 checkpoint 已通过本地 CPU 内容与加载核对，固定 holdout 作业 25622516 已完成并核对；E10／E07 的 Macro F1 为 56.62%／53.28%，结果见 [holdout 摘要](../reports/holdout/20261031_holdout_e10_e07_v1/SUMMARY.md)。跨配置选择是在 CV 后作出的，不宣称训练前注册。原 [评估与方案](../reports/experiments/20261031_e10/ASSESSMENT_AND_REFIT_PLAN.md)保留为决策过程，最新状态见 [双模型完成记录](../reports/refit/20261031_e10_e07_v1/README.md)。

- 各折从相同 ResNet-50 ImageNet V2 权重独立创建模型和 AdamW，不使用上一折权重；seed 为 42。
- 每折最多 100 epoch。只有折验证九类 Macro F1 严格大于历史最佳才更新 `best.pt`，同分保留较早 epoch。
- 连续 15 轮未提升则停止；每轮保存 `last.pt`。恢复须保持同一折、配置、数据和源码指纹，只恢复最后完整 epoch。
- 最佳 epoch 的概率用于报告五折均值、样本标准差及 pooled OOF。验证折参与选 epoch，CV 属于开发选模估计。
