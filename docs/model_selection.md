# 模型选择与固定 holdout 边界

## 2026-11-22 最终交付采用第 35 轮 GPM refit

原正式方案按五折最佳轮数 23、19、46、55、47 的中位数执行固定 46 轮 refit，并完成同一 1,037 例 holdout 的正式评估，Macro F1 为 53.75%，准确率为 68.66%。

随后进行两阶段探索。先比较 15、28、46 轮，再在观察前次结果后确定 1、5、10、15、20、25、30、35、46 的后续网格。后续网格使用一条新的完整 refit 轨迹，保留每个指定轮数的真实 checkpoint。项目于 11 月 22 日选择第 35 轮作为最终交付，Macro F1 为 58.68%、准确率为 75.12%，正确 779 / 1,037。

最终选择使用了已历史使用的固定 holdout，以上成绩按探索性选模后结果报告。原预定第 46 轮的 53.75% 作为正式基线列示。第 35 轮相对第 46 轮差值为 +4.93 个百分点，按 10,000 次同病例重采样得到单项比较的 95% 百分位区间为 −0.70 至 +10.70 个百分点。

第 35 轮保留 epoch=35、refit_complete=false，轨迹配置 max_epochs=46。新第 15、46 轮与对应历史模型逐张量完全一致，使用已验收预测。各轮结果、训练损失及 CV 覆盖折数见 [最终聚合结果](../reports/experiments/20261122_e14_gpm_final/SUMMARY.md)。
